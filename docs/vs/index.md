## Which converter fits

**[Markdownify MCP](/vs/markdownify-mcp)** is an MCP server built on MarkItDown, not the standalone converter measured above. Compare the install steps, supported formats, and web tools before switching.

**[Docling](/vs/docling)** is the closest to anymd on accuracy. Pick it for an in-process Python library with LangChain or LlamaIndex integrations, a lossless JSON document model, or vision-language models on a GPU. It scored higher on designed reports, scans and EPUB; on a CPU it was the slowest of the tools that converted every document.

**[Kreuzberg](/vs/kreuzberg)** has a Rust core with bindings for Python, TypeScript, Go, Java and more, reads 91+ formats including email and archives, and adds chunking and embeddings. It scored highest on HTML and tied anymd on spreadsheets; tables are its weak spot.

**[Unstructured](/vs/unstructured)** splits files into typed elements, with chunking and connectors for batch RAG ingestion in Python. Its text is close to anymd's; its tables are not.

**[MarkItDown](/vs/markitdown)** is Microsoft's lightweight Python converter, good on Office files, spreadsheets, HTML and designed reports. With its default options it returns no text for scanned PDFs.

**[Marker](/vs/marker)** uses vision-model OCR and an optional LLM, and is at its best on a GPU. Its OCR beat anymd on two of the three scans; on a 4-CPU runner it timed out on six documents.

**[pdftotext](/vs/pdftotext)** is Poppler's plain-text extractor: the quickest way to pull a born-digital PDF's text layer, often already installed. It reads PDFs only, with no OCR and no tables.

**anymd** is for agents that read PDFs, Office files, EPUB, HTML, scans and media through one MCP server on any CPU, with page anchors to cite and tables kept as Markdown. It is free and MIT licensed.

## Cloud APIs and other libraries

Three popular tools are not in the local AgentDocBench run above—two are metered cloud APIs requiring API keys and uploads, and one is an AGPL-3.0 Python library not yet submitted to `bench/`—so we compare architecture, privacy, licensing and pricing head to head:

- **[anymd vs LlamaParse](/vs/llamaparse)**: local MIT Rust binary with no API key or file uploads vs LlamaCloud's metered credit-per-page parsing API.
- **[anymd vs Mistral OCR](/vs/mistral-ocr)**: instant native PDF and Office parsing offline vs Mistral AI's cloud vision OCR API billed per 1,000 pages.
- **[anymd vs PyMuPDF4LLM](/vs/pymupdf4llm)**: permissive MIT Rust CLI and MCP server across PDF, Office and media vs Artifex's AGPL-3.0 Python PDF library.

## How the scores were measured

Every tool ran on GitHub-hosted Linux x86_64 runners with 4 CPUs, through its own CLI or Python API with default options unless its page says otherwise. Time is the wall time of a fresh process per file, start-up and model loading included. The scoring does not know which tool produced an output. GPUs, long-running servers and releases newer than the ones listed were not measured. The corpus, ground truth, scoring and raw results are public in [`bench/`](https://github.com/SylphxAI/anymd/tree/main/bench), and anyone can rerun them or [submit a tool](/docs/benchmarks#submit-a-tool).

## FAQ

**Which document to Markdown converter is the most accurate?**
On AgentDocBench, anymd scores 96.4 overall across 38 documents in 12 categories, followed by Docling. The scoreboard lists every tool's score, time and output tokens, and each head-to-head page lists the categories and documents where the other tool scores higher.

**Which converter is the fastest?**
pdftotext, on the PDFs it reads, because it copies the text layer and runs no OCR. Of the tools that converted all 38 documents, anymd is the fastest, at 11.5 seconds on a 4-CPU runner.

**Does anymd need Python or a GPU?**
No. anymd is a native Rust binary that runs on any CPU. The `npx` install needs Node 18 or newer; Homebrew, Scoop and Docker install the same binary without Node.

**Is the benchmark biased toward anymd?**
It lives in the anymd repository, so you can check it: the scoring does not know which tool produced an output, the corpus and ground truth are public, and the categories where anymd loses are published. Anyone can rerun it or add a tool.

**Is anymd free?**
Yes. anymd is MIT licensed, including the CLI, the MCP server, OCR and transcripts. anymd Pro is an optional one-time purchase, US$29 or the local price in 16 currencies, that adds PDF cite-check and video timelines and frames.
