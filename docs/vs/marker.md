# anymd vs Marker

Both tools turn PDFs and office files into Markdown for LLMs. [Marker](https://github.com/datalab-to/marker), from Datalab, is a Python library and CLI built around its Surya OCR models, and is at its fastest on a GPU. anymd is one native Rust binary, MIT licensed, that is also an MCP server and needs no GPU. On a 4-CPU machine and the 38 public documents of [AgentDocBench](/guide/benchmarks?entry_surface=seo_vs-marker), anymd scores **96.4** to Marker's **71.0**. Marker converted 30 of the 38; on those 30, anymd took **4.64 s** instead of **7,104.5 s** and returned **20% fewer output tokens**.

**Where Marker shines:** on two of the three scanned PDFs, Marker's OCR beat anymd (93.3 vs 71.6 and 66.7 vs 62.1). Its third scan timed out, which pulls its scanned-category score down.

### How it was measured

Both tools ran on GitHub-hosted Linux x86_64 runners with 4 CPUs: Marker 2.0.0 through `marker_single` on 2026-09-25, in its default CPU mode with no LLM and image extraction off, and anymd 8.2.0 on 2026-10-01. Time is the wall time of a fresh process per file, start-up and model loading included: one timed run after a warm-up for Marker, and the median of three runs for anymd. Each document had 900 s. Marker's README reports much higher throughput on a GPU and with a long-running server; neither was measured, and neither was Marker 2.2.0, released after the run. Tokens are counted with `o200k_base`.

The benchmark lives in the anymd repository. The scoring does not know which tool produced an output, and the corpus, ground truth, scoring and raw results are public in [`bench/`](https://github.com/SylphxAI/anymd/tree/main/bench). Anyone can rerun it or [submit a tool](/guide/benchmarks#submit-a-tool).

## Why agent builders pick anymd

### No GPU, no model server, no PyTorch

`npx -y @sylphx/anymd setup` adds anymd to Claude Code, Codex, Cursor, VS Code, Claude Desktop, Windsurf and Gemini CLI at once. Homebrew (`brew install sylphxai/tap/anymd`), Scoop (`scoop install anymd` from the `SylphxAI/scoop-bucket` bucket), Cargo (`cargo install anymd`) and Docker (`ghcr.io/sylphxai/anymd`) install the same binary. It runs on a laptop, in CI or in a small container, with nothing to download before it converts a born-digital document.

### Every document, in seconds, on a CPU

On the 4-CPU runner anymd converted all 38 documents, including the two CSV files and the six that timed out for Marker. On the 30 that both converted, anymd took 4.64 s in total.

### Layouts that usually break stay readable

anymd reads PDF glyph positions, so it keeps columns, tables and forms in order: reading order 98.8 vs 76.8 and table cells F1 92.2 vs 60.9. The largest category gaps are spreadsheets (100.0 vs 38.1), math papers (96.7 vs 56.7), HTML (99.6 vs 60.6) and forms (98.0 vs 61.0).

### MIT, for any use

anymd is MIT licensed, with no revenue limit and no separate commercial licence. The optional OCR models it can download on request are Apache 2.0.

## When Marker is the better fit

- You have a GPU and want vision-model OCR for degraded scans, handwriting or dense equations.
- You want an LLM in the loop (`--use_llm`) to merge tables across pages or pull values out of forms.
- You need JSON, HTML or chunked output with layout blocks, or Marker's interactive viewer.

## Switch in one line

```bash
marker_single report.pdf --output_format markdown --output_dir out/   # Marker
anymd report.pdf -o report.md                                         # anymd, after npm install -g @sylphx/anymd
```

For MCP, add `npx -y @sylphx/anymd` to your client, or run `npx -y @sylphx/anymd setup` to add it to every client. With Docker:

```bash
docker run --rm -v "$PWD:/data" ghcr.io/sylphxai/anymd report.pdf > report.md
```

## FAQ

**Is anymd a drop-in replacement for Marker?**
For Markdown output, mostly: `anymd report.pdf -o report.md` replaces `marker_single report.pdf --output_format markdown`, and `npx -y @sylphx/anymd setup` adds anymd to your MCP clients. Code that imports `marker` cannot switch today, because anymd's Python package is not on PyPI yet.

**Is anymd faster than Marker?**
On a 4-CPU runner, yes: on the 30 documents both converted, anymd took 4.64 seconds and Marker 7,104.5 seconds, each timed as a fresh process per file with start-up and model loading included. Marker on a GPU was not measured.

**Why does Marker score 71.0?**
A document a tool did not convert scores 0. Marker timed out on 6 of the 38 documents after 900 seconds each and does not read the 2 CSV files. On the 30 documents both converted, the overall is 95.5 for anymd and 89.3 for Marker.

**Does anymd need a GPU or Python?**
No. anymd is a native Rust binary that runs on any CPU. The `npx` install needs Node 18 or newer; Homebrew, Scoop and Docker install the same binary without Node.

**Can I use anymd commercially?**
Yes. anymd is MIT licensed, with no revenue limit. Marker's code is Apache 2.0, and its README says its model weights are free for research, personal use and startups under US$5M funding or revenue, with a commercial licence from Datalab beyond that.

**Is anymd free?**
Yes. anymd is MIT licensed, including the CLI, the MCP server, OCR and transcripts. anymd Pro is an optional one-time purchase, US$29 or the local price in 16 currencies, that adds PDF cite-check and video timelines and frames.
