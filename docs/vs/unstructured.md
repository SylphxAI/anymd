# anymd vs Unstructured

Both tools prepare documents for LLM and RAG pipelines. [Unstructured](https://github.com/Unstructured-IO/unstructured) is an Apache 2.0 Python library that splits files into typed elements, with connectors for batch ingestion. anymd is one native Rust binary, MIT licensed, that returns Markdown and is also an MCP server. On the 38 public documents of [AgentDocBench](/guide/benchmarks?entry_surface=seo_vs-unstructured), anymd scores **96.4** to Unstructured's **81.2**, converts all 38 in **11.5 s** instead of **346.5 s**, and returns **11% fewer output tokens**. Tables make the biggest difference: table cells F1 is **92.2** against **38.4**.

**The words are there; the structure is not.** Text F1 is almost the same (97.2 vs 97.1), but with its default strategy Unstructured keeps few table cells in place (38.4) and scores 60.8 on two-column papers, so an agent gets the right words in the wrong shape.

### How it was measured

Both tools ran on GitHub-hosted Linux x86_64 runners with 4 CPUs: Unstructured 0.27.8 on 2026-09-25, through `partition()` with its default `auto` strategy, which does not use the `hi_res` layout model, and then `elements_to_md()`; and anymd 8.2.0 on 2026-10-01. Time is the wall time of a fresh process per file, start-up included: one timed run for Unstructured, and the median of three runs for anymd. The `hi_res` strategy, the hosted Transform API and Unstructured 0.27.37, released after the run, were not measured. Tokens are counted with `o200k_base`.

The benchmark lives in the anymd repository. The scoring does not know which tool produced an output, and the corpus, ground truth, scoring and raw results are public in [`bench/`](https://github.com/SylphxAI/anymd/tree/main/bench). Anyone can rerun it or [submit a tool](/guide/benchmarks#submit-a-tool).

## Why agent builders pick anymd

### One binary instead of a Python stack

`npx -y @sylphx/anymd setup` adds anymd to Claude Code, Codex, Cursor, VS Code, Claude Desktop, Windsurf and Gemini CLI at once. Homebrew (`brew install sylphxai/tap/anymd`), Scoop (`scoop install anymd` from the `SylphxAI/scoop-bucket` bucket), Cargo (`cargo install anymd`) and Docker (`ghcr.io/sylphxai/anymd`) install the same binary. There is no virtual environment, and no poppler or LibreOffice to install: Office files, EPUB and HTML are parsed natively.

### Tables and columns stay intact

anymd rebuilds tables from ruling lines and aligned whitespace and reads two-column pages in order. The largest category gaps are two-column papers (98.1 vs 60.8), CJK documents (99.1 vs 71.8), financial tables (95.2 vs 71.9) and forms (98.0 vs 74.6).

### 30× faster, in fewer tokens

On the same 4-CPU runner, anymd converted the 38 documents in 11.5 s and Unstructured in 346.5 s, and anymd's output was 368,659 tokens to Unstructured's 414,333. Pages come back with `<!-- page N -->` anchors, so an agent can cite where an answer came from.

### Nothing leaves your machine

anymd sends no usage analytics. It goes online only when you pass a URL or explicitly ask it to download a model, and `--allow-dir` keeps the MCP server inside one folder.

## When Unstructured is the better fit

- You want typed elements with metadata and built-in chunking inside a Python RAG pipeline.
- You ingest from many sources and destinations through its connectors.
- You plan to use its `hi_res` layout model or the hosted Transform API, which this benchmark did not measure.
- Your corpus is mostly EPUB, where Unstructured scored slightly higher (99.1 vs 98.9).

## FAQ

**Is anymd a drop-in replacement for Unstructured?**
For Markdown output from the command line or an MCP client, yes: `anymd report.pdf -o report.md`, or `npx -y @sylphx/anymd setup` for your MCP clients. Code that calls `partition()` and works with elements cannot switch today, because anymd's Python package is not on PyPI yet and anymd returns Markdown, not elements.

**Is anymd faster than Unstructured?**
On AgentDocBench, anymd converted all 38 documents in 11.5 seconds and Unstructured in 346.5 seconds on the same 4-CPU runner, each timed as a fresh process per file with start-up included.

**Why is Unstructured's table score low?**
With its default `auto` strategy, Unstructured kept few table cells in their rows and columns: table cells F1 is 38.4 against anymd's 92.2. Its `hi_res` strategy, which uses a layout model, was not measured.

**Does anymd need Python?**
No. anymd is a native Rust binary. The `npx` install needs Node 18 or newer; Homebrew, Scoop and Docker install the same binary without Node.

**Is the benchmark biased toward anymd?**
It lives in the anymd repository, so you can check it: the scoring does not know which tool produced an output, the corpus and ground truth are public, and the categories where anymd loses are published. Anyone can rerun it or add a tool.

**Is anymd free?**
Yes. anymd is MIT licensed, including the CLI, the MCP server, OCR and transcripts. anymd Pro is an optional one-time purchase, US$29 or the local price in 16 currencies, that adds PDF cite-check and video timelines and frames.
