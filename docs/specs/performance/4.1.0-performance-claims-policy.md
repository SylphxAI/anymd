Date: 2026-07-24T19:41:34Z

## Authorized when evidence present

1. Suite `status=admissible_pass` with `rustFromRegistry=true` for exact published version
2. Independent review `performanceClaimsAuthorized=true` for that version/SHA
3. Claims must name:
   - host class (e.g. linux-x64)
   - mode (`persistent_warm` and/or `startup_inclusive`)
   - task family
   - warm-cache behavior for identical local re-reads

## Current evidence

- Suite: `verification/pdf-reader-same-host-ab-suite-4.1.0-registry.json`
- Report: `docs/specs/performance/4.1.0-same-host-performance-report.md`

## Forbidden

- Collapsing modes into one unqualified “Nx faster”
- Using 4.0.2 registry baseline as if it included warm cache
- Multi-host extrapolation from one host
