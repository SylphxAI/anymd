# Benchmarks

**AgentDocBench** is an open, reproducible benchmark for "document → Markdown for agents". It measures what an
agent needs from a converter: the words verbatim, in reading order, tables intact, fast, and in as few tokens as
possible. It runs anymd, Docling, Marker, MarkItDown, Kreuzberg, Unstructured, and pdftotext on the same
license-clean documents on GitHub-hosted runners.

anymd is one of the tools measured, and this benchmark lives in its repository. The scoring does not know which
tool produced an output, the corpus and ground truth are public, and the categories where anymd loses are in the
tables below like everything else. The harness, corpus, ground truth, and raw results are in
[`bench/`](https://github.com/SylphxAI/anymd/tree/main/bench).

## How it is scored

Every output is normalized the same way (Unicode NFKC, Markdown and HTML markup removed, whitespace collapsed,
curly quotes straightened, spaces between CJK characters dropped) and compared with the document's ground truth:

- **Sentences**: key sentences copied verbatim from the document must appear verbatim. Glued words, split
  columns, or dropped lines fail the sentence. For scanned documents these are the sentences a correct OCR
  produces.
- **Text F1**: bag-of-words F1 against a reference text (the PDF text layer, the DOCX/PPTX XML text, or the
  EPUB spine text). Recall drops when text is lost, precision when noise is added.
- **Reading order**: headings and passage openings must appear in order. The score is the longest in-order
  chain divided by the number of strings, so two-column interleaving and scrambled sections both cost.
- **Table cells F1**: every ground-truth table row is matched to the output row with the longest in-order run
  of equal cells. Recall is matched cells over truth cells; on complete tables, precision is matched cells over
  the cells of the output tables they came from. Pipe tables and HTML tables both count; plain text scores 0.
- **Document score** is the mean of the scores that apply; **category score** is the mean over its documents,
  with a failed, timed-out, or unsupported document counting 0; **overall** is the mean of the category scores.
- **Time** is the wall time of a fresh process per file (start-up included), median of 3 runs (1 run for tools
  that take minutes per document), after one untimed warm-up. **Tokens** are `o200k_base`.

The full method, the ground-truth schema, and the known limits are in
[`bench/README.md`](https://github.com/SylphxAI/anymd/blob/main/bench/README.md).

## Reproduce

```bash
python3 bench/fetch.py .cache/bench-corpus          # download and verify the corpus
cargo build --release -p pdf-reader-mcp-server     # anymd
python3 -m venv .venv && .venv/bin/pip install -r bench/requirements/harness.txt -r bench/requirements/markitdown.txt

ANYMD_BIN=target/release/anymd .venv/bin/python bench/run.py --tool anymd \
  --corpus .cache/bench-corpus --out bench/results/anymd.json
.venv/bin/python bench/run.py --tool markitdown --corpus .cache/bench-corpus --out bench/results/markitdown.json
.venv/bin/python bench/leaderboard.py --print
```

The [Benchmark workflow](https://github.com/SylphxAI/anymd/actions/workflows/benchmark.yml) runs every tool on its
own GitHub-hosted runner with the same system packages (poppler, tesseract with Chinese and Japanese, pandoc),
and publishes the merged results and every Markdown output as an artifact.

## Submit a tool

Add an adapter in `bench/adapters/<tool>.py` (a name, a version, and the command that prints Markdown), pin the
tool in `bench/requirements/<tool>.txt`, add it to the workflow matrix, and open a pull request. The workflow runs
the benchmark; commit the resulting `bench/results/<tool>.json` and the regenerated leaderboard. Details are in
[Submitting a tool](https://github.com/SylphxAI/anymd/blob/main/bench/README.md#submitting-a-tool).

The official `@modelcontextprotocol/server-pdf` is not included because it has no headless text path: it renders
PDFs in an interactive viewer, and its `read_pdf_bytes` tool returns base64-encoded bytes.
