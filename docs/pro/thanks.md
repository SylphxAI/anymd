# Thank you for buying anymd Pro

Your licence token is on its way by email, usually within a few hours. Check your spam folder if you do not see it.

## Activate it

Run:

```bash
anymd pro activate '<your token>'
anymd pro status
```

or set it in the environment:

```bash
export ANYMD_PRO_TOKEN='<your token>'
```

Pro works offline and needs no account. Problems with the token? Email hi@sylphx.com.
